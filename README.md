# HERYKA.exe

Experiência interativa criada especialmente para Heryka, combinando programação,
academia e a origem da conexão pelo Instagram.

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Tecnologias

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
